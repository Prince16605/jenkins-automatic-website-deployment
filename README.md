🚀 **My First Jenkins CI/CD Mini Project — Automatic Website Deployment on AWS EC2!**

I’m excited to share my hands-on DevOps project, where I worked on automating website deployment using Jenkins and GitHub. 💻

🎯 **Project Workflow:**

🔹 Developer pushes code to GitHub  
🔹 GitHub webhook triggers the Jenkins pipeline  
🔹 Jenkins checks out the latest source code  
🔹 Automated validation checks run  
🔹 Website files are deployed to an AWS EC2 instance  
🔹 Nginx serves the updated website  

🛠️ **Technologies Used:**
- Jenkins — CI/CD pipeline automation
- Git & GitHub — Source code management
- GitHub Webhooks — Automatic build triggering
- AWS EC2 — Cloud server
- Ubuntu Linux — Operating system
- Nginx — Web server
- HTML & CSS — Website development
